#可解释性机器学习——城市应用
##项目简介
基于 XGBoost + SHAP 的可解释性机器学习预测项目，用于探索城市数据中的特征影响机制（此项目为城市因素与昼夜温差拟合）。

##技术栈
- Python / Jupyter Notebook
- XGBoost（梯度提升模型）
- SHAP（可解释 AI）
- pandas, numpy, matplotlib

##主要内容
- 数据预处理与特征工程
- XGBoost 模型训练与调参
- SHAP 依赖图与交互图分析
- 模型可解释性可视化

##关联方向
对 "智慧城市、区域可持续发展、机器学习、气候环境治理、人机协同规划实验"等议题感兴趣。
